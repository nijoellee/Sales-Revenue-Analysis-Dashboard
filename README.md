# Sales & Revenue Analysis Dashboard

This project is a **Power BI dashboard** created to analyze sales and revenue performance using the Global Superstore dataset. It focuses on KPI tracking, revenue trends, product performance, and interactive business analysis through charts, filters, and slicers.

## Project Objective

The goal of this dashboard is to help users:

- Track total sales and profit performance
- Analyze revenue trends over time
- Identify top-performing product categories
- Explore product and shipping insights
- Generate business insights through interactive visualizations

## Tools Used

- Microsoft Power BI

## Data Source

- Global Superstore dataset from Kaggle
- Dataset includes sales, profit, product, market, customer, and shipping details

## Task Alignment

This project matches the internship task requirements in the following ways:

- **Data Import:** Sales data was used from the Global Superstore dataset for dashboard creation
- **KPI Visualization:** The dashboard includes total sales, total profit, yearly performance, and category-based insights
- **Interactive Analysis:** Filters and slicers are used to explore data by year, quarter, category, market, and order priority
- **Business Insights:** The dashboards highlight trends, product performance, and shipping behavior to support decision-making

## Dashboard Overview

This project contains three dashboard views:

1. Sales Analysis Dashboard
2. Product Analysis Dashboard
3. Shipping Analysis Dashboard

## Sales Analysis Dashboard

The Sales Analysis Dashboard helps analyze overall business performance through key revenue and profit indicators.

### Key Insights

- Total Sales: **3 Million**
- Total Profit: **400.9K**
- Sales in 2014: **1 Million**
- Profit in 2014: **119.11K**
- Technology contributed **46% of total profit**
- March and April 2014 recorded high sales revenue
- December showed the lowest sales revenue in the selected period

### Interactive Features

- Filter by year
- Filter by quarter
- Analyze category-level performance
- Review sales trends over time

## Product Analysis Dashboard

The Product Analysis Dashboard focuses on product categories, quantity ordered, and sub-category performance.

### Key Insights

- Office supplies had the highest quantity ordered
- Tables were sold at an average discount of **28%** in 2014
- Product-level analysis helps identify strong and weak-performing categories

### Interactive Features

- Filter by year
- Filter by market
- Drill into category and sub-category analysis

## Shipping Analysis Dashboard

The Shipping Analysis Dashboard helps evaluate shipping preferences, order priority behavior, and shipping cost distribution.

### Key Insights

- **53%** of orders used Standard shipping mode
- Same Day shipping was the least preferred mode
- **41%** of critical-priority orders were shipped through First Class
- **100%** of low-priority orders were shipped through Standard Class
- APAC had the highest shipping cost, followed by EU and US

### Interactive Features

- Compare shipping modes
- Analyze order priority by ship mode
- Study regional shipping cost patterns
